# Heaxo Marketing — UI Kit

A hi-fi recreation of a Heaxo public marketing site.

## Files

- `index.html` — homepage: nav, hero, feature grid, code showcase, CTA, footer.
- `MarketingNav.jsx` — top nav with logo, links, primary CTA.
- `Hero.jsx` — hero section with display headline, subhead, CTA, viewport preview.
- `FeatureGrid.jsx` — 3-column feature grid with iconography.
- `CodeShowcase.jsx` — split section: code block on one side, prose on the other.
- `CTA.jsx` — closing CTA band.
- `Footer.jsx` — full footer with link columns.

## Note

Built without access to the real Heaxo marketing site or codebase — copy and layout extrapolated from category convention.
